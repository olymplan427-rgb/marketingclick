시작하기 전에
모든 AI 기능(블로그 작성, 뉴스 소재 추천, 이미지 홍보문구, 지역 트렌드 리포트)은 학원 프로필을 기준으로 결과를 만듭니다. "블로그 작성" 페이지 Step 1에서 학원명·키워드·주소 등을 한 번만 입력해두면 다른 기능에서도 그대로 재사용됩니다.
💡 기능마다 크레딧이 소모됩니다. 신규 가입 시 500 크레딧이 지급되며, 잔여량은 사이드바 "크레딧"에서 확인할 수 있어요.
블로그 작성
주제와 키워드만 입력하면 네이버 블로그에 바로 붙여넣을 수 있는 완성 글과 이미지 프롬프트까지 한 번에 만들어줍니다.
학원 프로필 입력 (최초 1회)
학원명·주요 키워드·과목·주소 등을 입력하고 저장합니다. 여러 지점이 있다면 "+ 새 프로필"로 추가할 수 있습니다.
글 작성 정보 입력
글 유형(교육칼럼/입시정보/학원홍보 등), 분위기, 주제, 타겟 독자층, 키워드를 입력합니다. 자유 서술로 대략 적고 "AI 분석해서 아래 채우기"를 누르면 항목이 자동으로 채워집니다.
Step 2 — 변형 요소 확인/수정: AI가 제안한 소제목·구성을 확인하고 원하는 대로 수정합니다.
Step 3 — 완성 글 확인: 완성된 본문과 썸네일/본문 이미지 프롬프트를 확인하고 [복사] 버튼으로 순수 텍스트만 복사해 네이버 SmartEditor에 붙여넣습니다.
💡 [복사] 버튼은 서식 없는 순수 텍스트만 복사하기 때문에 SmartEditor에 붙여넣어도 폰트·스타일이 깨지지 않습니다.
작성 히스토리
이전에 작성한 블로그 글을 모아보고, 글 유형·검색어로 필터링할 수 있습니다. 본인이 작성한 글만 표시됩니다.
1. 글 유형을 선택하거나 제목·키워드·태그로 검색합니다.
2. 목록에서 글 제목을 클릭하면 오른쪽에 전체 본문이 표시됩니다.
뉴스 소재 추천
최근 교육 뉴스를 모아 이미 다룬 소재는 제외하고, 학원 블로그로 쓰기 좋은 주제를 AI가 추천합니다.
1. "최근 교육 뉴스 불러와 주제 추천받기" 버튼을 누릅니다.
2. 추천된 주제 목록에서 마음에 드는 것을 클릭해 상세 내용을 확인합니다.
3. "이 주제로 쓰기"를 누르면 블로그 작성 탭으로 이동하며 주제/키워드가 자동으로 채워집니다.
주변 학원 검색
학원 프로필의 위치를 기준으로 반경 내 경쟁 수학학원을 찾고, 각 학원의 블로그 리뷰 보유 여부까지 함께 확인합니다. 아래 번호 순서대로 진행하세요.
기준 위치
학원 프로필을 선택합니다. 주소가 등록되어 있으면 더 정확하게 검색됩니다.
검색 반경
500m/1km/2km 중 선택합니다.
검색 키워드
기본값은 "수학학원"이며 필요시 수정합니다.
주변 학원 검색
버튼을 누르면 인근 학원 목록과 블로그 리뷰 보유 여부가 표시됩니다. 블로그가 있는 학원은 클릭해서 리뷰 글을 모아볼 수 있습니다.
💡 정확도를 높이려면 "블로그 작성" Step 1에서 학원 주소를 미리 등록해두세요.
지역 트렌드 리포트
우리 학원이 속한 지역(구/군/시)의 수학학원들이 최근 3개월간 진행한 이벤트·이슈를 블로그에서 모아 트렌드와 콘텐츠 주제까지 정리합니다.
조회 지역
자동 추출되지 않으면 직접 입력합니다 (예: 중랑구).
리포트 생성
버튼을 누르면 언급량 추이, 주요 학원 프로필, 콘텐츠 패턴, 시사점, 블로그 주제 추천이 순서대로 표시됩니다.
💡 리포트 하단 추천 주제 카드의 "이 주제로 쓰기"를 누르면 블로그 작성으로 바로 이어집니다.
이미지 만들기 (성적우수)
배경을 고르고 합격자 명단을 붙여넣으면 인스타그램 게시용 성적우수 이미지가 바로 완성됩니다.
배경 선택
준비된 배경 중 하나를 고르거나 "+ 이미지 추가"로 직접 업로드합니다.
제목 텍스트 편집
"+ 텍스트 추가"로 원하는 문구를 넣고 위치·글꼴을 조정합니다.
명단 입력
학교명/이름을 줄바꿈으로 입력하거나 엑셀에서 복사해 붙여넣습니다. 2열/3열 레이아웃을 선택할 수 있습니다.
오른쪽 미리보기에서 결과를 확인하고 "PNG 다운로드"로 저장합니다.
크레딧
기능별로 소모되는 크레딧과 이번 달 잔여량, 사용 내역을 확인합니다.
1. 상단에서 현재 잔여 크레딧을 확인합니다. 매월 초 자동으로 리셋됩니다.
2. 아래 표에서 언제 어떤 기능에 얼마가 사용되었는지 확인할 수 있습니다.
의견보내기 / 문의
불편한 점이나 아이디어를 관리자에게 직접 전달할 수 있는 게시판입니다. 작성한 글은 본인과 관리자만 볼 수 있습니다.
내용 입력
문의하실 내용을 작성합니다.
등록
버튼을 누르면 문의가 등록되고, 관리자가 답변을 남기면 같은 스레드에 이어서 표시됩니다.
💡 급한 문의는 사이드바 "문의하기"(카카오톡 채널)를 이용해주세요.
